# Security

Please report suspected vulnerabilities through this repository's private
vulnerability-reporting channel. Do not disclose security-sensitive details in
a public issue, pull request, discussion, or commit.

Include the affected URL, a minimal reproduction, the expected impact, and any
relevant browser or platform details. MFENX will acknowledge receipt and
coordinate disclosure after triage.

This policy covers the website delivery repository and content served from
`mfenx.com`. Reports about a separate MFENX product should identify that product
without attaching proprietary source or customer data.
