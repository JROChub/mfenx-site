Deployment limits

Three validators share one host in sfo3 and one failure domain. Quorum is two; operational status requires all three. The runtime uses a deterministic leader without leader failover, so quorum alone does not guarantee continued operation after a process failure.

Storage and memory are bounded. Admission can stop when capacity is reached. Empty blocks are scheduled daily. The public RPC is read only; signed transaction submission is restricted to the operator's protected loopback interface.
