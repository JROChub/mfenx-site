Behavioral admission records

Three open models, each admitted through MFENX's pinned-contract behavioral evaluation — the receipt proves not only that the bytes are the admitted bytes, but that the exact contracted model produced the expected decisions on a fixed, seeded evaluation dataset, with bit-deterministic replay. A modified copy with identical-looking behavior to the naked eye was blocked by the behavioral gate. Verify any of these yourself with the free CLI: no account, no trust in us required.

Verify one

# mfenx-gate 1.0.1 (URL + pin confirmed against mfenx.com/docs 2026-10-22)
pip install 'mfenx-gate @ https://mfenx.com/gate/downloads/mfenx_gate-1.0.1-py3-none-any.whl#sha256=14659e64788110d48e0b0069c81556c489096cc0650b34cf8a67a6cbb355d090'

What these receipts are — and aren't.
  • They are behavioral-evaluation records (onnx-finite-evaluation/v1, profile ckodmk/cpu-f32-batch1-classification/v1): each binds the exact model bytes, a frozen release contract (model, dataset, device, claims), and the observed decision outcomes over a finite seeded dataset. The gate runs the model and a deterministic replay on onnxruntime CPU and issues a receipt only when every required claim passes.
  • These are self-admissions: source and candidate are the same public checkpoint. The passing decision_invariant claims prove the admission machinery works, not that any of these models is good.
  • Evaluation labels are each reference model's own argmax decisions on seeded noise inputs (PCG64(20261022), standard normal) — reference-behavior labels, declared plainly, not a ground-truth benchmark. Anyone can reproduce the exact dataset bytes from the seed.
  • Signed under the same demonstration key as the integrity records — issuer "MFENX public-model proof (local test key)", key_id sha256:0c2b883d981d3b927f06f68dec707408535abb8e0317ca34d276d68f83656953 — not a production trust root. Commercial releases are signed under the customer's own release authority.
  • They expire 2026-11-21 (30-day test validity); they are re-issued monthly.
  • The ONNX model zoo publishes no SHA-256 reference digests for model files, so the file digests below are measured from the downloaded bytes and recorded in the contracts; both downloads used the canonical validated-path URLs over HTTPS.
