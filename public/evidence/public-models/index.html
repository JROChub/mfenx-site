Public models / integrity receipts

Verify one in five minutes

Download the model from its Hugging Face repo, download the receipt and the public key below, and run three commands. Either the bytes in your hand are exactly the bytes the receipt binds, or the check rejects them. 

pip install 'mfenx-gate @ https://mfenx.com/gate/downloads/mfenx_gate-1.0.0-py3-none-any.whl'
# 1. download model.safetensors from the model's Hugging Face repo (link per model below)
# 2. download the model's receipt and proof-issuer-public.der from this page
mfenx-gate verify distilbert-base-uncased-receipt.json --trusted-public-key proof-issuer-public.der --model model.safetensors
# expected: {"status": "ATTESTATION_VERIFIED", "artifactStatus": "MATCH"}

Use the same command with each model's own receipt. A copy of the model file with one byte changed is rejected by the same check.

What these receipts are, and are not. They are integrity-tier records (safetensors-integrity/v1, decision NOT_EVALUATED): each binds the exact bytes of one model file to a signed receipt. They do not claim behavioral evaluation. The published behavioral record (Optdigits) is at mfenx.com/evidence/. They are signed under a demonstration key, issuer "MFENX public-model proof (local test key)", key_id sha256:0c2b883d981d3b927f06f68dec707408535abb8e0317ca34d276d68f83656953, not a production trust root. Commercial releases are signed under the customer's own release authority. They expire on 2026-11-20 (30-day test validity).
