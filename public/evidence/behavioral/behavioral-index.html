Behavioral admission records

Three open ONNX models, each admitted through a pinned-contract behavioral evaluation. The receipt proves not only that the bytes are the admitted bytes, but that the exact contracted model produced the expected decisions on a fixed, seeded dataset, with bit-deterministic replay. A modified copy that looks identical to the naked eye is blocked by the behavioral gate. Verify any of these yourself with the free CLI. No account, and no trust in us, required.

Verify one in five minutes

Download the model from its ONNX model zoo link below, download the receipt and the public key, and run three commands. The behavioral check runs the model and a deterministic replay of the pinned evaluation: it either passes every required claim, or the model is not admitted. 

pip install 'mfenx-gate @ https://mfenx.com/gate/downloads/mfenx_gate-1.0.1-py3-none-any.whl#sha256=14659e64788110d48e0b0069c81556c489096cc0650b34cf8a67a6cbb355d090'
# 1. download the .onnx model from the ONNX model zoo link per model below
# 2. download the model's receipt and proof-issuer-public.der from this page
mfenx-gate verify mobilenetv2-onnx-admission-receipt.json --trusted-public-key proof-issuer-public.der --model mobilenetv2-12.onnx
# expected: {"status": "ATTESTATION_VERIFIED", "artifactStatus": "MATCH", "behavioralStatus": "ISSUER_ATTESTED_FINITE_EVALUATION"}

Use the same command with each model's own receipt. Both tamper controls below, the one-byte flip and the perturbed-weight variant, are rejected by the same check.

What these receipts are, and are not. They are behavioral-evaluation records (onnx-finite-evaluation/v1, profile ckodmk/cpu-f32-batch1-classification/v1): each binds the exact model bytes, a frozen release contract (model, dataset, device, claims), and the observed decision outcomes over a finite seeded dataset. They are self-admissions: source and candidate are the same public checkpoint, so the passing decision_invariant claims prove the admission machinery works, not that any model is good. Evaluation labels are each reference model's own argmax decisions on seeded noise inputs (PCG64(20261022), standard normal), declared plainly, not a ground-truth benchmark. They are signed under the same demonstration key as the integrity records, issuer "MFENX public-model proof (local test key)", key_id sha256:0c2b883d981d3b927f06f68dec707408535abb8e0317ca34d276d68f83656953, not a production trust root. Commercial releases are signed under the customer's own release authority. They expire on 2026-11-21 (30-day test validity). The ONNX model zoo publishes no SHA-256 reference digests for model files, so the file digests below are measured from the downloaded bytes and recorded in the contracts.
