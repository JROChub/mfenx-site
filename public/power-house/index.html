Power House

Keep the artifact and its evidence together.

Power House is a Rust library for deterministic verification, artifact identity and recorded lineage. Its portable formats let you inspect how an artifact connects to its history.

Using the library

Read the verification record.

A fingerprint identifies recorded content. Verification checks the proof relation and trust conditions relevant to the application. The library keeps these operations distinct.

Optional external proof attachments do not change an artifact’s core Power House identity. Review the documented verification rules before relying on an attachment.

Start with the published interfaces.

cargo add power_house

The Rust documentation describes the available modules and feature flags. Memory Capsule documentation covers verification, replay and challenge workflows.
