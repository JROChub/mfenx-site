EXECUTION LAW

Each tile carries exact algebraic content

Wrapping-i32 arithmetic keeps the low 32 bits of a result. QQfenx stores each tensor tile as a normalized payload and an exponent s: the exact number of trailing zero bits shared by every value. A zero tile has s = 32.

T = 2s · T̂   (mod 232)

When sA + sB < 32, a contribution A × B needs only q = 32 − sA − sB quotient bits. QQfenx computes the normalized payload in ℤ/2qℤ and restores the shared power of two to recover the original 32-bit answer exactly.

After accumulation, QQfenx measures the actual output again. Cancellation can create additional shared trailing zeros; the normalized result then determines the quotient used by the next operation.

ZERO-IDEAL RULE sA + sB ≥ 32 A × B = 0   mod 232

Both input tiles can be nonzero. Their product is divisible by 232, so its low 32 bits are zero. The complete tile contribution requires zero payload multiply-accumulates.
